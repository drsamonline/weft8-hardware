what you are looking at

Ten small programs, and the result each one must produce — worked out by hand from the instruction set, not recorded from either implementation. The table below runs every program on the Loom's JavaScript machine in your browser and compares it with that hand-computed result. The C port (c/weft8.c) is compiled and checked against the same table in CI, on every push.

the three that must agree

1. the hand-computed expectation
2. the C machine — c/weft8.c, ~180 lines
3. the Loom's JavaScript machine — weft8.js

Two implementations and one independent answer. If any of the three drifts, the build goes red.
