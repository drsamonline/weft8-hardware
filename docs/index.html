The same 8-bit computer,
not just in a browser.

The Loom's Weft-8 is about 180 lines of C here as well as a single JavaScript file — sixteen registers, four flags, 256 bytes, twenty-seven instructions. Eleven programs, with results worked out by hand, must agree across all three: the hand computation, the C machine, and the JavaScript one. If any of them drifts, the build goes red.

/* the whole machine, in one switch */
case W8_ADD:
    va = m->r[a]; vb = m->r[b];
    res = (unsigned)va + vb;
    m->r[a] = (uint8_t)res;
    m->c = res > 0xFF;
    m->v = (((va ^ res) &
             (vb ^ res)) & 0x80) != 0;
    set_nz(m, m->r[a]);
    break;

Why a C port is the honest test

A machine described in one language can hide a mistake inside that language's habits. A second implementation, written from the same specification and checked against an independent answer, cannot.
